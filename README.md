# AI Automation Portfolio

Hands-on projects from my learning path in **Power Platform, Copilot Studio and Claude**.
Each folder is one project built while completing a course or certification.

I work on business process automation in logistics. These projects use **synthetic data only** —
no company, customer or shipment data from any employer.
